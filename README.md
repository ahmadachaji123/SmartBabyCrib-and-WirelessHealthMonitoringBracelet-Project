Smart Baby Crib – Final Year Project
A fully integrated Smart Baby Crib System developed as a Final Year Project in Mechatronics Engineering, focusing on baby safety, health monitoring, automation, and remote access.

🔹 Features
Wireless Health Monitoring: Heart rate, body temperature, and SpO₂ displayed on crib screen and mobile app
System Status: Bracelet battery, ambient temperature; humidity fixed at 70% (sensor damaged)
Remote Monitoring & Control: Mobile app connected via Wi-Fi to an online database, full control from anywhere
Synchronized Control: Swing, lights, music, system status updated in real time between crib and app
Auto Mode: Can be enabled/disabled from crib or phone; currently triggered by noise, planned upgrade to baby-cry detection
Health Data Visualization: 7-day real-time graphs (HR, temperature, SpO₂) on app or web browser; older data deleted automatically

🛠 Technologies
Embedded C/C++ for microcontrollers
Wireless sensors and communication modules
Mobile app & web dashboard for control and visualization
Mechanical design & structural analysis
